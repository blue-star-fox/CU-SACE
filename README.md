## ✨ 简介

SAC 是**只在房主（主机）端运行**的反作弊插件。

- **纯主机端**：客户端无需安装、无感知，不影响正常玩家。
- **面向行为类作弊**：覆盖移动、战斗、交互、小游戏、医疗、状态等多类作弊行为。
- **可记录、可处置**：违规计分、证据留存、封禁与 OP 白名单；处置方式可选（仅记录 / 阈值踢出 / 撤销异常行为）。
- **可视化**：管理面板（F7）与调试监视器（F8），支持中英文界面切换。
- **数据集中**：全部运行数据统一放在 `SAC/` 文件夹，方便备份与迁移。

> 设计取向：**宁可漏报，尽量不误伤**。多数判定需要连续确认，并为加入游戏、地图切换、被传送等情形提供豁免窗口。

## 🎯 能识别哪些作弊

> 这里只说明“能识别哪些作弊行为”，不涉及识别方式。

- 🏃 **移动**：加速 / 瞬移 / 穿墙 / 飞行 / 空中跳 / 高跳 / 贴墙连跳 / 反布娃娃 / 伪装喷气背包 / 反负重
- ⚔ **战斗**：近战超距与攻速 / 射速 / 无后座
- 📦 **交互**：隔墙与超距拾取/交互、推人连发/超距/穿墙、异常背人
- 🔓 **小游戏**：秒开锁 / 秒完成 / 自动按键 / 自动绷带 / 秒截肢 / 秒拔碎片 / 自动发电 / 一键引爆
- 🧬 **状态**：道具瞬移、状态伪造、计时异常
- 🛰 **身份**：作弊模组的互认标记
- 🚫 **无法识别**：纯客户端视觉类作弊（ESP / 自瞄 / 透视 / 全亮等）不产生主机可见行为，不在识别范围内

## 🚀 安装与使用

### 前置要求

- 安装 **BepInEx 5**（建议 `5.4.x` 及以上）到游戏目录。
- 已安装 **Casualties Unknown** 与联机模组 **KrokoshaCasualtiesMP**。
- 插件会在启动时**检查本机运行环境**（游戏版本 / 联机 MOD 版本 / BepInEx 版本），不符时弹出提示。

### 安装

1. 把 `SAC.dll` 复制到：
   ```
   游戏目录\BepInEx\plugins\SAC.dll
   ```
2. 启动游戏，插件自动加载。
3. **只需房主安装**。进入多人房间时请确认自己是**房主（主机）**。

> ⚠️ 首次加载会显示一次**使用公告**（说明插件的能力边界与已知不足），点击“我已知晓”即可。

### 快捷键

| 按键 | 功能 |
|---|---|
| `F7` | 打开/关闭**反作弊管理面板** |
| `F8` | 打开/关闭**调试监视器** |

### 管理面板（F7）

- **玩家**：在线列表、**OP / 踢出 / 封禁**。
- **违规**：违规记录 / 疑似名单 / 封禁列表。
- **设置**：分组参数、界面语言、窗口外观，修改即时生效。
- **游戏状态**：帧率、内存、联机状态、延迟等。
- **关于**：功能介绍与运行环境。

### 控制台命令（设置页底部输入框）

```
get / set / options / kick / ban / unban / banlist / reload / save
```

```

└── SAC/                         运行数据（自动生成）

    ├── suspected-cheaters.json  疑似作弊名单
    ├── oplist.json              OP 白名单
    ├── packet-filter.json       数据包过滤器配置（调试）
    └── banlist.json             封禁列表
```

## 🖼️ 界面一览

- **主面板（F7）**：圆角深色主题、多选项卡（emoji 图标 + 文字）、可自由拉伸、切换动画、透明度可调。
- **调试监视器（F8）**：玩家实时信息、疑似异常数据包、最近日志，可折叠。
- **作弊信息小窗**：独立悬浮窗，显示违规作弊者信息，不绑定按键。
- **中英文界面**：启动时跟随系统语言，也可在设置中手动切换。

## ⚠️ 说明与免责

- **反作弊并非万能**：纯客户端视觉类作弊（ESP、自瞄辅助、透视、全亮等）不产生主机可见行为，主机端无法识别；部分由客户端结算的功能只能间接推断；存在误报/漏报的可能，请以证据为准、谨慎处置。
- **由一人独立开发**（小狐狸），更新与排错可能不够及时，敬请谅解。
- **兼容性**：插件会修改游戏逻辑，可能与其它 BepInEx 插件 / 联机 MOD **冲突**（尤其是同样改动移动/网络逻辑的 MOD）。如遇异常，请先停用其它插件逐一排查。
- 如果你发现误报或漏报，欢迎反馈，我们会持续完善。
